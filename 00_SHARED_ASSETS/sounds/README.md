# KHO ÂM THANH DÙNG CHUNG

Thư mục lưu trữ hiệu ứng âm thanh dùng cho toàn bộ thư viện game HTML5.

## Danh mục âm thanh

| Tên file | Chức năng |
|---|---|
| flip.mp3 | Âm thanh lật thẻ |
| correct.mp3 | Trả lời đúng |
| wrong.mp3 | Trả lời sai |
| win.mp3 | Chiến thắng |
| click.mp3 | Nhấn nút |
| collect.mp3 | Thu thập vật phẩm |
| level-up.mp3 | Lên cấp |
| start.mp3 | Bắt đầu trò chơi |
| game-over.mp3 | Kết thúc trò chơi |
| notification.mp3 | Thông báo |

## Quy ước

- Định dạng ưu tiên: MP3, OGG.
- Tên file viết thường, không dấu, không khoảng trắng.
- Âm thanh ngắn, rõ ràng, phù hợp học sinh tiểu học.
- Các game sử dụng chung tài nguyên trong thư mục này.
